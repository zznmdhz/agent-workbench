# Mac v0.4.2 测试说明

当前 Mac 应用由本仓库源码在本机生成，尚未作为 GitHub 安装包发布。它只读 Codex、Claude Code 和 Hermes 的原始数据；工作台自己的索引保存在 `~/Library/Application Support/AgentWorkbench/data/`。

## 打开应用

1. 在仓库根目录运行 `bash packaging/build_mac.sh`，生成 `dist/mac/AgentWorkbench.app`。
2. 双击 `AgentWorkbench.app`。应用在后台启动本机服务，并在默认浏览器打开 `http://127.0.0.1:8765/`。若浏览器没有自动打开，可手动访问该地址。
3. 页面右上角显示 `v0.4.2` 才是本轮测试版。点击“关闭工作台”可退出；再次双击应用即可重新打开。

第一次读取 Mac 上的历史 Codex 日志可能较久。页面出现“同步中…”时等待读取完成；之后同一数据库会增量更新。不要用已发布的 Windows v0.4.1 安装包验证这轮界面。

## 建议核对

1. 页面顶部切换“全部／Codex／Claude／Hermes”；核心指标、来源、模型、热力图和会话列表应随筛选更新。
2. 分别点“年／月／周／日”。年视图按日显示全年，月视图按日显示当月，周视图为 7 天，日视图为 24 小时。点击有记录的日期进入该日小时视图。
3. 改动开始和结束日期，再选模型；筛选状态在点击热力图日期后仍应保留。
4. Codex 会话应优先显示可读名称；长标题可悬停查看全文。“所选时段会话”指该时段有用量记录，不代表正在运行。
5. Hermes 只有会话／模型汇总，已计入上方总量的部分会在热力图下标明“无法按日或小时分配”。若来源缺失，先确认本机是否有对应原始记录。

发现问题时记录筛选日期、Agent、模型、来源状态和页面现象。不要提交原始会话、数据库或未脱敏的截图到 GitHub。

## 开发者检查

`bash packaging/smoke_mac.sh` 使用隔离空来源和测试数据库检查 Mac 打包应用的服务、页面资源及用量接口。Windows v0.4.2 的安装、升级和自动更新仍需回到 Windows 实机验证。
