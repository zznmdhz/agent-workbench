# November 2026 source sync

This candidate contains the portable application source and selected tests, not a dump of a running installation. Follow the main README for the Python environment and the web build. Keep the service on loopback or an explicitly trusted interface, and use a separate data directory for test work. Before upgrading an existing deployment, take a consistent SQLite backup and preserve collector state. Some older readers cannot interpret compressed archive payloads written by the newer code; do not point them at a live upgraded database.

A session is joined by canonical computer, agent and native session identity. The card's Token value describes archived lifetime usage for that session, not consumption clipped to the list date. Content bytes are measured from source text and tool fields, not SQLite disk usage. Missing values remain unknown, and incomplete sums may appear as lower bounds. Requests, windows, activity and time estimates are separate measures.

Focused tests of the synchronized source can be run without live data using `PYTHONPATH=src python3 -m unittest discover -s tests -p 'test_session_content_size.py'`. This branch does not include native chats, database files, credentials, launchd configuration or packaged web assets. Machine-specific deployment and backup remain separate, and the sync does not prove complete history, cross-platform operation or a response-time guarantee.
