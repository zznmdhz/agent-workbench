# Mac 会话与时间视图核验（2026-09-28）

## 范围与来源

本轮在 macOS 上完成实际测试；代码继续使用 macOS／Windows 两套默认路径。读取来源均为本机原生记录，未修改 `~/.codex`、`~/.claude` 或 `~/.hermes/state.db`。私有消息正文、数据库与截图未提交仓库。

- Codex：252 个 JSONL 文件；完成事件中实测有任务标识、开始／完成时间及毫秒时长。未完成任务不会计入已证实时间。
- Claude Code：87 个 JSONL 文件；保存用户／助手时间与正文，但缺可等同 Codex 已完成任务的明确运行区间。9 月 28 日本机没有 Claude 可计算片段；8 月 7 日的 Claude 日期查询返回 13 个会话、38 个估算片段，抽样会话文字可按页读取。
- Hermes：本机 `state.db` 可读；消息有时间和最终回复标记。会话级开始／结束可能跨越闲置，因此只用消息配对作估算；计划任务也在数据内。

9 月 28 日的实测查询返回 24 个小时格、13 个会话、22 个已证实或估算的时间区间。Agent 累计大于所有区间的时间并集，说明并行去重按预期生效。实际使用数据会随着当天新会话变化，不在此文档固定私人用量或消息内容。
