# 会话导航、关键节点与文件夹定位（v0.5.3）

## 交互口径

左栏负责快速识别会话：标题、最近消息、用时、会话内容大小和打开来源目录。Codex／Claude 的大小是关联原始日志文件当前占用的字节数；Hermes 标“内容约”，是该会话消息与工具字段的字节数。来源缺失时显示未知并禁用目录按钮。右栏标题显示所选日期范围内的用户提问轮次和 Agent 用时，以及整个原生会话中**已确认**涉及的文件数。用户提问轮次按原始用户消息计数，过滤 Codex 注入的环境说明；它不是模型调用数。

“关键节点”按原始顺序保留用户输入及每轮最后的 Agent 回复。Hermes 有 `stop` 结束标记时优先选择该回复；否则取下一条用户输入前最后一条 Agent 回复。Codex 环境说明从关键节点中隐藏。“完整详情”保留全部可读取的用户／Agent 文字消息。这是结构筛选，不做模型摘要；关键节点仍可能省略有用的中间进展，可随时切回完整详情。

## 本机文件夹操作

来源、工作目录与文件操作记录的按钮只打开**所在文件夹**，不执行文件。接口要求本机桌面模式、同源访问和页面 CSRF；文件路径必须属于当前会话的原始来源或已记录的文件线索。目标目录在本机已不存在时返回提示。macOS 调用 Finder，Windows 调用资源管理器；Windows 代码路径已覆盖，仍待 Windows 实机验证。

文件历史继续保留同一路径的多次写入记录。已确认文件数按路径去重；嵌套补丁等无法确认结果的线索单独显示。Shell、外部程序和未留下可解析日志的产物不会被编造成已确认记录。页面的文件大小是**当前**大小，并非每次写入当时的历史版本。

## Hermes 共享数据库

Hermes 的多条会话记录确实位于同一个 `state.db`，可以按 `session_id` 查询某个会话的消息、工具调用和内容字节数，也能逻辑导出该会话的记录。但 SQLite 数据页、索引、空闲页和可能存在的日志文件由多个会话共用，不能把 `state.db` 的物理磁盘占用准确归到某一个会话。因此界面将“内容约”与“数据库占用”和运行时 RAM 明确区分。
