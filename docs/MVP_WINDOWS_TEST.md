# Windows v0.3.0 MVP 安装与测试

## 安装

1. 若旧版正在运行，在旧网页点击“关闭工作台”。旧版卸载和旧数据清理由维护者完成后，确认开始菜单中不再出现旧版。
2. 从 [GitHub Releases](https://github.com/zznmdhz/agent-workbench/releases) 下载 `AgentWorkbench-Setup-0.3.0-Windows-x64.exe`。双击安装，采用默认选项即可；不要求管理员权限。
3. 从开始菜单打开 **Agent Workbench**。程序会在后台运行并自动打开默认浏览器的 `http://127.0.0.1:8765/`。首次在网页创建至少 12 位密码。整个过程无需打开命令窗口。
4. 首次读取较多 Codex 日志可能等待约 20 秒或更久；页面“同步中…”结束后检查数值。如果本机没有 Codex 原生会话日志，会显示来源缺失提示。

## 测试清单

1. **数据有依据：** 页面显示“Codex · 本机原生日志”、已扫描文件数和本轮更新数；请求、Token、会话至少一项有数据。若最近没有使用 Codex，尝试近 15 天，不要把无数据直接判断为故障。
2. **时间切换：** 依次点单日、近 7 天、近 10 天、近 15 天。结束日期可更改。各卡片、每日用量、模型和会话列表应同步变化。
3. **口径核对：** “新输入 + 缓存读取 = 原始输入”；“处理 Token = 原始输入 + 输出”。缓存是输入的一部分，不能再额外加一次。费用未计价是有意的，不能当成 0 元。
4. **模型筛选：** 在模型下拉框选择一个模型，请求数和 Token 不应超过“全部模型”的相同日期范围。恢复“全部模型”后数值恢复。
5. **会话明细：** 点击任一活跃会话，检查时间、模型、原始输入、缓存读取和输出的逐请求行。关闭明细后可继续选另一条。这里只核对用量，不展示对话正文。
6. **关闭与重开：** 点击右上角“关闭工作台”，网页应提示已关闭；从开始菜单再次打开，应回到原有数据和登录状态。

## 如果结果不对

先记录所选日期、模型、页面“已扫描文件”与“日志暂未计入”提示、异常数字，以及一条对应 Codex 会话的时间。不要上传原始 `~/.codex` 会话文件、工作台数据库或密码。问题报告可在 [GitHub Issues](https://github.com/zznmdhz/agent-workbench/issues) 提交脱敏截图与上述信息。若网页无法打开，检查任务管理器是否已有 AgentWorkbench 进程，并从开始菜单重新打开；仍失败时将 `%LOCALAPPDATA%\AgentWorkbench\data\desktop.log` 的**脱敏错误片段**附上。

当前测试版只验收 Windows 本机 Codex Token 与会话统计。Hermes Token、完整对话、文件、Mac/NAS 和跨机管理会在后续阶段分别设计与验收。
