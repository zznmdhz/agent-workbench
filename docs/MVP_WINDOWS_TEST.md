# Windows v0.8.0 使用与测试

普通用户只需安装并从开始菜单打开 Agent Workbench，或者访问已收藏的 `http://127.0.0.1:8765/`。无密码、无命令窗口。已有 Windows 本机升级不要求删除旧底库。

1. 看右下角通知区的小图标（可能在隐藏图标中），打开菜单，检查状态及最近采集时间；页面和标签页显示同样的运行状态。
2. 关闭浏览器，再访问网址，数据仍可读；后台采集不依赖标签页。退出后台是单独操作。
3. 开始日期选择年初，结束日期选择今天，再切今天／近七天／全部历史。核对来源覆盖；早于来源记录的历史不能补造。
4. 切 Codex／Claude／Hermes，模型和主卡一起筛选；检查 `新输入 + 缓存读取 + 缓存写入 + 输出 = 处理 Token`。
5. 年／月／周／日热力图分别按日、日、日、小时展示。Hermes 无日期证据的聚合独立显示，不伪造日／小时数据。
6. 浏览会话，按标题／内容／文件路径搜索；打开关键节点与完整详情、文件操作历史，试文件夹定位。文件索引不等于文件备份，远端或消失的路径无法打开。
7. 运行时间区分可信任务事件与消息估算；导入合成跨日记录不应成为几百小时的已证实时长。
8. 从“后台管理”暂停，再恢复；已有历史仍能查询。从同处重启，页面应自动重连。
9. 多次打开开始菜单入口应复用同一后台。异常退出恢复由系统计划任务管理，正常退出不会立即重开。登录启动和电池策略的设计见[后台说明](project/LOCAL_BACKGROUND_V0.8.md)。

发布附件记录开发者实测结果。没有在本次操作中重启整台电脑或完成 72 小时连续运行；Mac/NAS 同步需后续实机验收。便携版不自动更新、不注册登录启动任务。

反馈异常时提供版本、筛选范围、Agent 和脱敏截图；不要公开原始对话、数据库和私有路径。
