# Agent Workbench Windows 便携版

这是无需安装的 Windows 便携包。默认只在当前电脑的 `127.0.0.1:8765` 提供网页。数据库、设备凭据和采集队列保存在解压目录下 `data/`，请把整个目录放在仅自己可访问的位置，不要把 `data/` 上传或分享。

解压 ZIP 后双击 `AgentWorkbench.exe`。浏览器会自动打开 `http://127.0.0.1:8765/`；首次使用直接在网页创建至少 12 位管理员密码，完成后自动进入工作台。本机存在的 Codex/Hermes 来源会自动登记并以**仅统计**策略采集，首次扫描可能需要几分钟。程序在后台运行，可从网页左侧点击“关闭工作台”。

没有任何 Agent 数据时仍可登录和打开空白工作台。本机采集原始目录为只读，不会自动修改 Codex/Hermes 配置。删除本工具数据时先在网页关闭工作台，再自行备份并移走 `data/`；不要删除 Agent 原数据。

忘记密码时，先在网页登录页点击“关闭工作台”，再双击 `AgentWorkbenchReset.exe`。确认后会清除旧密码和登录状态，在网页重新设置；会话与统计数据保留。

跨电脑使用需要在目标电脑另行配对采集器，并保证服务地址可达。Mac、NAS 和双机交接的实际环境验收尚未完成。便携包不含系统服务、自启动、自动更新或代码签名。详细状态见公开仓库 README、`docs/project/ROADMAP.md`。
