# Agent Workbench Windows 便携预览版

这是开发预览包，不是 NAS/Mac 正式安装包。默认只在当前 Windows 电脑的 `127.0.0.1:8765` 提供网页。数据库、配对 token 与采集队列保存在解压目录下 `data/`，请把整个目录放在仅自己可访问的位置，不要把 `data/` 上传或分享。

1. 解压 ZIP，双击 `Start-AgentWorkbench.cmd`。首次启动在弹出的窗口设置至少 12 位管理员密码。浏览器会打开 `http://127.0.0.1:8765/`，用刚设的密码登录。窗口需保持开启。
2. 如果希望读取本机活动，在网页“设备与设置”生成配对码，双击 `Pair-This-PC.cmd` 输入配对码。脚本默认把存在的 Codex/Hermes 来源设为**仅统计**，并在窗口显示来源 ID。
3. 将来源 ID 粘贴到网页“登记来源”，选中本机设备并确认。双击 `Collect-This-PC.cmd` 开始扫描，保持该窗口开启；回到网页刷新查看。

没有任何 Agent 数据时仍可登录和打开空白工作台。本机采集原始目录为只读；`.cmd` 脚本不会自动修改 Codex/Hermes 配置。想停止服务或采集，关闭对应窗口即可。删除本工具数据时先关闭窗口，再自行备份并移走 `data/`；不要删除 Agent 原数据。

Windows 可直接启动不代表 NAS、Mac 或双机交接已验收。此预览包不含系统服务、自启动、自动更新或代码签名。详细状态和安全限制见公开仓库 README、`docs/project/ROADMAP.md`。
