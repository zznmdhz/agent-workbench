# Agent Workbench v0.8.0 Windows 便携版

解压整个 ZIP 后双击 `AgentWorkbench.exe`，浏览器直接打开 `http://127.0.0.1:8765/`，无需密码。右下角通知区显示状态菜单；关闭浏览器仍运行，退出后台才停止。

数据保存在解压目录的 `data/`，含本机对话和文件路径，不能上传或分享。读取 Codex、Claude、Hermes，只读原始来源。支持任意起止日期，但 Hermes 聚合用量不能准确拆到每日／小时。

便携版不注册登录启动、不自动更新。不要与安装版同时运行同一默认端口。安装版及完整说明见 [GitHub Releases](https://github.com/zznmdhz/agent-workbench/releases/tag/v0.8.0)。
